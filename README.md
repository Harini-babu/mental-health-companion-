
**Mental Health & Burnout Risk Analysis System**

An end-to-end Machine Learning framework designed to monitor, evaluate, and predict student mental well-being and academic burnout. By analyzing daily habits, lifestyle patterns, and academic pressure points, this project provides early interventions to help students maintain a healthy balance between productivity and mental health.

**Key Features**

* **Burnout Prediction:** ML classification models trained to detect early signs of mental fatigue and stress.
* **Feature Integration:** Tracks critical temporal variables including sleep duration, daily screen time, study workload, and exam schedules.
* **Behavioral Insights:** Feature importance analysis identifying key contributors to academic exhaustion.
* **Interactive Dashboard:** Visualizations highlighting stress trends over time and high-risk periods.

**Tech Stack**

* **Language & Analysis:** Python, Pandas, NumPy, Scikit-learn
* **Visualization:** Seaborn, Matplotlib
